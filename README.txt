FitQuest V0.4.3

Korrektur XP-Logik: Jeder NEU gespeicherte Satz bringt einmal +10 XP. Bereits gespeicherte Sätze bleiben beim erneuten Öffnen sichtbar und erzeugen niemals erneut XP. Ein später hinzugefügter weiterer Satz bringt wieder XP. Das reine Abschließen einer Übung vergibt keine normalen XP doppelt; neue persönliche Rekorde können weiterhin einen separaten Bonus auslösen.

Live-Trainingsbegleitung, Links/Rechts-Protokoll und Kurzhantelgewicht pro Hantel bleiben erhalten.

GitHub Pages: Alle 8 Dateien direkt ins Repository-Hauptverzeichnis hochladen und bestehende Dateien ersetzen.
